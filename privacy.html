Privacy Policy

Last updated: October 19, 2026

1. About this application

VPS Backup Manager is a private, owner-operated tool for backing up the operator's own virtual private server. It is not offered to the public as a service. This public information website describes the tool's intended Google Drive integration; it does not itself perform backups or request Google authorization.

2. Information processed

When configured and authorized by the owner, the private backup workflow may handle selected server files, database exports, backup metadata (such as dates and result statuses) and Google OAuth credentials required for Drive access. Backups can contain application data; the operator is responsible for choosing which server data is included.

3. Google Drive access and purpose

Google Drive access is used solely to create, upload, inspect, verify, retrieve and manage backup files owned by the operator. Authorization is initiated by the Google Account owner. Access is not used for advertising, profiling, unrelated analytics or selling data. The application should request only the permissions needed for its backup workflow.

4. Storage and security

The intended workflow encrypts backup data before transfer to the operator's Google Drive account. Sensitive OAuth tokens, encryption keys and server credentials are not published in this repository or served by this website. Security settings and access controls are managed on the private server and in the operator's Google Account.

5. Data sharing

Backups are stored in the Google Drive account chosen by the owner and are processed by Google under the applicable Google services terms and privacy policies. The operator does not sell backup data or knowingly share it with advertisers or unrelated third parties.

6. Retention and deletion

The operator controls the retention schedule for backups and can delete backup files through Google Drive or the backup management tool. Google OAuth access can be revoked at any time in Google Account settings. The private server's credential configuration can also be removed by the operator.

7. This public website

These static pages do not include custom analytics, advertising scripts, cookies, forms or sign-in features. As the site is hosted on GitHub Pages, GitHub may process technical access information according to its own privacy practices.

8. Changes to this policy

This document may be updated when the backup workflow changes. Any material updates will be reflected here with an updated revision date.

9. Contact

Questions about this personal project can be directed to the repository owner through the GitHub repository's issue tracker. Do not include passwords, backup contents or other secrets in public issues.
